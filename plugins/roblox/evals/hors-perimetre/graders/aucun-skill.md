LE cas qui mesure le sur-déclenchement. Une question technique sans rapport avec Roblox ne doit charger AUCUN skill du plugin : chacun coûte son corps en contexte pour rien, et oriente la réponse vers un métier qui n'a rien à faire ici. Un plugin qui se déclenche sur tout est aussi cassé qu'un plugin qui ne se déclenche jamais — mais le premier ne se voit pas.
